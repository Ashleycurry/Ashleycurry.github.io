C++ 在 C 的基础上引入了面向对象、泛型编程和强大的标准库。这套笔记按课程顺序整理，内容覆盖 C++ 入门、面向对象、内存管理、模板和 STL 容器，目标是建立可持续扩展的 C++ 知识结构。

学习路线

建议先掌握语言基础和类的基本使用，再学习对象生命周期、资源管理和模板。完成 STL 容器部分后，应重点练习”能用、明理、能扩展”三个层次：先会使用接口，再理解底层结构，最后尝试实现或扩展组件。

知识重点

类和对象

  • 使用 class 定义数据和行为，理解封装、访问控制和成员函数；
  • 掌握构造函数、析构函数、拷贝构造和赋值运算符；
  • 理解编译器生成的默认成员函数，以及何时需要手动实现；
  • 使用初始化列表正确初始化引用、const 成员和没有默认构造函数的成员对象。

内存管理

  • 区分栈、堆、静态区、常量区和代码区；
  • 理解动态内存分配、释放和扩容；
  • 区分 C 风格的 malloc/free 与 C++ 风格的 new/delete；
  • 关注内存泄漏、悬空指针、重复释放和越界访问等问题。

模板与泛型编程

  • 使用函数模板和类模板编写类型无关的代码；
  • 理解模板实例化和参数推导，学习非类型模板参数、模板特化和偏特化；
  • 在复用性、可读性和编译复杂度之间进行权衡。

STL 与容器

  • 理解容器、迭代器、算法和函数对象等 STL 组件之间的关系；
  • 掌握 string 的字符串管理，理解 vector 的连续存储、size、capacity、resize 和 reserve；
  • 理解 list 的节点结构、迭代器和插入删除特点；
  • 使用 stack 和 queue 解决后进先出、先进先出等问题。
