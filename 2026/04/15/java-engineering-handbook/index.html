Java 工程实践手册：三阶段学习路线与案例体系

Java 学习与工程实践的课程资料与源码案例，按三个阶段推进：Java 核心与 AI 开发基础、Java 核心与 AI 开发进阶、AI 赋能 Web 开发。

这份手册整理 Java 学习与工程实践的课程资料、源码案例和学习笔记，内容按三个阶段循序推进：阶段一为 Java 核心与 AI 开发基础；阶段二为 Java 核心与 AI 开发进阶；阶段三为 AI 赋能 Web 开发。源码案例按”一个知识点对应一个小案例”的风格编写，并配有中文注释，方便对照课件学习。

学习路线

资料与环境

  • 课件目录：3 个阶段，48 份 PPTX 与 1 份 PDF，共 49 份；
  • 编程语言：Java（JDK 21）；
  • 开发工具：IntelliJ IDEA；
  • 工程组织：按阶段划分为独立 IDEA 工程，每个章节对应一个独立模块；
  • 源码包名：com.myproject.*。

阶段一：Java 核心与 AI 开发基础

从开发环境到面向对象高级，共 15 份课件，配套 Chapter_01 ~ Chapter_06 源码案例：

  • Chapter_01 环境搭建：Java 背景、JDK 安装、HelloWorld 与程序执行原理、IDEA 使用；
  • Chapter_02 基础语法：注释、字面量、变量与八种基本数据类型、运算符、方法与类型转换；
  • Chapter_03 流程控制：if / switch 分支、for / while / do-while 循环、break / continue、Random 猜数字游戏；
  • Chapter_04 数组：静态与动态初始化、元素访问、遍历应用（求和、最大值、反转）、二维数组；
  • Chapter_05 面向对象基础：类与对象、封装与权限修饰符、构造方法、this、static、标准 JavaBean；
  • Chapter_06 面向对象高级：继承与方法重写、抽象类、final、Object 类与 toString 重写。

阶段二：Java 核心与 AI 开发进阶

  • 集合高级：ArrayList / LinkedList 与 HashSet / LinkedHashSet / TreeSet 体系；
  • Stream 流：Lambda 表达式与流式操作；
  • 异常：异常体系、处理方式与自定义异常；
  • File 类：常用 API 与递归；
  • 常用 API：Math、System、包装类、BigDecimal 与 Arrays；
  • IO 流：字节流与字符流；
  • 多线程：线程安全与同步、线程池；
  • 网络编程：网络三要素、UDP 与 TCP 通信；
  • Java 高级技术：枚举、类加载器、反射、注解与动态代理。

阶段三：AI 赋能 Web 开发

从 Web 基础到完整项目部署：

  • Web 基础：HTML + CSS、JavaScript、Vue3、Web 服务器与静态资源；
  • 后端基础：Maven 依赖管理、数据库、JDBC / MyBatis / MyBatisPlus；
  • SpringBoot：登录认证、AOP、Maven 高级、SpringBoot 原理与分层架构总结；
  • 后端实战：Tlias 智能学习辅助系统（部门管理与员工管理：条件分页查询、新增、修改、删除、事务与文件上传）；
  • 前端实战：Vue 工程化 + ElementPlus 的 Tlias 案例；
  • 部署：Linux 项目部署与 Docker 容器化。

如何运行

  • 使用 IntelliJ IDEA 打开对应阶段的工程目录（例如 src/Phase_001）；
  • 工程默认使用 JDK 21，若本机 JDK 版本不同，可在 File → Project Structure 中调整 Project SDK；
  • 每个案例类都包含 main 方法，可右键直接运行；
  • 所有案例仅依赖 JDK 标准库，无需额外安装依赖。
