Python 工程实践手册：13 个案例走完入门路径

面向 Python 初学者的课程笔记与案例仓库，从环境搭建到 NumPy，13 个可运行案例覆盖基础语法、函数与模块、容器、类与文件、异常、多线程与 pip。

Python 是自动化、数据处理和 AI 应用的通用语言。这份手册整理了从环境搭建到 NumPy 的 13 个课程主题，每个章节都对应一个可运行的案例脚本，强调”先理解基础概念，再通过小案例练习，最后形成清晰、可维护、可复用的代码习惯”。

学习路线

Python 环境 -> 基础语法 -> 条件与循环 -> 函数与模块 -> 容器 -> 类与文件 -> 异常 -> 内置函数 -> 多线程 -> pip -> NumPy

课程案例位于 src/，每个目录使用三位编号和英文名称，便于阅读和检索。

工程化约定

  • 每个案例都可以作为独立脚本运行，使用 if __name__ == "__main__": 作为入口；
  • 函数和类使用中文文档字符串，说明职责、参数、返回值和可预期异常；
  • 优先使用清晰的命名、明确的边界校验和标准库能力；
  • 文件资源使用上下文管理器，线程共享数据使用锁保护；
  • 示例保持单一主题，避免为了展示功能而引入无关复杂度。
