个人介绍

个人介绍：XiaoGao —— 嵌入式软件与 LLM 应用开发者，以及这个博客的由来。

ABOUT

你好，我是 XiaoGao

一名嵌入式软件与 LLM 应用开发者，在嵌入式和智能应用的交叉地带工作：一边贴着硬件写可预测的代码，一边把模型、工具和数据接进真实的工作流。

我的工程方向很朴素：

  • 贴近机器构建：用可预测、资源可控的软件构建底层系统；
  • 让知识可用：把文档和知识变成真正有用的检索增强体验；
  • 连接智能与现实：把模型、工具、API 与实际工作流连起来；
  • 保持系统清晰：用干净的接口和文档，让系统的每个部分都可理解。

这个博客

「XiaoGao 的代码笔记」是我所有学习笔记与项目记录的归档站。

从 2026 年春天开始，我把学习路上积累的资料系统整理成了 GitHub 仓库，内容覆盖：

方向 内容
编程语言 C / C++ / Python / Java 的学习笔记与工程手册
硬件设计 模拟电路、数字电路与计算机组成、原理图与 PCB 设计
嵌入式开发 STM32 单片机全外设、FreeRTOS 实时操作系统、实战工程项目
Linux 与工具 Linux 系统管理、Shell 脚本、正则表达式、Linux 应用层开发
机器人 ROS / ROS 2 入门、步进电机同步运动控制
计算机视觉 OpenCV 图像处理从入门到特征匹配
项目实战 客户管理系统、家庭记账软件等 C 语言工程实践

博客里的每一篇文章，都对应一个公开的 GitHub 仓库，包含完整的课件、源码和文档。学习笔记记录知识，项目实战记录踩过的坑——两样都是给未来的自己留的索引。

技术栈

嵌入式软件：C / C++ / ARM Cortex-M / RISC-V、FreeRTOS / Zephyr / Embedded Linux，GPIO、UART、I2C、SPI、ADC、PWM、CAN 等外设驱动，TCP/IP、MQTT、Wi-Fi、BLE 设备互联。

LLM 与 RAG 应用：Python / FastAPI / Pydantic，文档摄取与切分、向量检索与重排序、提示词设计与工具调用、检索质量评估。

工程原则

  • 让所有权和失效模式显式化；
  • 偏好职责清晰的小模块；
  • 把校验、可观测性和文档当作产品特性；
  • 度量检索质量，而不是相信一个演示；
  • 为有用的行为优化，而不只是为惊艳的输出。
